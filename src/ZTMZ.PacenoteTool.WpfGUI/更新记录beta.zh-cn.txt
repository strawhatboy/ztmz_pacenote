v2.99.99.44-3.0-rc16

* 修复主页“游戏设置”“游戏悬浮仪表盘”和“领航员”标题不会随界面字体大小设置实时调整的问题；新下载的推荐字体现在无需重启即可立即应用。
* ZTMZ 在 ACR 赛段已开始后接入时，会恢复赛段状态，不会重复播报发车倒计时或 Go 语音。
* 本地化 ACR 共享内存、bridge 和前置检查状态文本。
* 提醒 ACR 与 ZTMZ 必须以相同 Windows 权限级别运行，否则实时 bridge 无法传送路书。
* 修复安装后网页仪表盘客户端文件和内置字体缺失的问题。
* 新增悬浮仪表盘使用提示，并让调试仪表盘显示可读的游戏状态名称。

v2.99.99.43-3.0-rc15

* 修复 rc14 在新电脑上向 ACR 注入 bridge 后，领航员语音可能完全不播报的问题。
* 新增 ACR 发车流程，使用 ZTMZ 的 5、4、3、2、1 倒计时和 Go 语音。
* 新增 ACR 的正常完赛、取消资格、碰撞和出界处理。
* 扩充 ACR 路书语音覆盖，包含距离播报及常见的危险提示和地标。
* ACR 获得焦点时仪表盘仍会保持显示，并且只会在赛段开始后出现。
* 启用实验性 bridge 后，不论 ACR 与 ZTMZ 的启动顺序，均会在 ACR 可注入时提示注入。
* 安装程序会在缺少 ASP.NET Core Runtime 时，于 .NET Desktop Runtime 后自动安装；中国标准时区使用 Gitee 镜像。
* 新增界面字体大小设置，可在 85% 至 130% 间调整。
* 新增离线路书脚本编辑器，支持语法校验、导入 CrewChief JSON、随播放高亮、批量调整距离和导出路书 PDF。

v2.99.99.42-3.0-rc14

* 新增实验性的 Assetto Corsa Rally 支持，可选择启用游戏内实时路书转发。
* 新增明确的 DLL 注入风险提示、本地化桥接状态，以及主页诊断中的桥接可用性状态。
* 修复主页布局：展开游戏设置后可正常滚动，诊断状态栏始终可见。
* 新增可配置的界面字体：可选择系统字体，或按需下载并应用推荐的开源字体。
* 新增在线语音包“[AI] 哈基米”：基于 CosyVoice 3 生成，每个路书标记提供多个随机播报片段。

v2.99.99.41-3.0-rc13

* 新增 BeamNG.drive 拉力模式支持：实时领航员语音、倒计时、赛段状态、遥测数据，以及拉力桥接模块的自动安装和更新。
* 新增 BeamNG.drive 和 Richard Burns Rally 的车辆损坏仪表盘，并提供可选的系统故障语音提示。
* 改进游戏检测、赛段生命周期和仪表盘显示的可靠性。

v2.99.99.40-3.0-rc12

* 汇总 v2.99.99.36-rc9 之后的改进：升级到 .NET 10 和 WPF-UI，调整并可安全修复游戏遥测端口，同时提高 UDP 接收和音频播放稳定性。
* 当 Windows 配置为中国标准时间时，安装程序会使用适合中国网络环境的 .NET 桌面运行时下载镜像。
* 改进最小化启动时的更新提示：发现新版本后会通过托盘图标通知，并可从托盘菜单中打开更新对话框。
