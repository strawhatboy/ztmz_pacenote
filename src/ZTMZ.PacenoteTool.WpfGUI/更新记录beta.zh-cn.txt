v2.99.99.46-3.0-rc18

* 路书编辑器新增主窗口内打印弹层，提供准确且实时刷新的 PDF 分页预览、实体打印机与 PDF 输出、纸张、方向、页边距、可配置格式与位置的页码、页码范围和份数设置；打印会保留背景色，并移除浏览器生成的文件路径页眉页脚。
* 升级音频播放栈至 NAudio 3，并改用明确标记为媒体会话的 WASAPI 共享模式；修复播放路书时被 Windows 误判为“通信活动”、导致游戏及其他应用声音自动降低或静音的问题，同时改进输出设备识别和切换稳定性。
* 修复界面使用德语、西班牙语、法语、意大利语、日语、韩语、巴西葡萄牙语或俄语时，游戏专属说明、安装引导、桥接警告、诊断和设置仍显示英文的问题。
* 语言选择器现在使用每种语言自己的名称，不再随 Windows 显示语言整组变成英文或中文。
* 新增原生悬浮窗和网页仪表盘均可使用的图形路书 dashboard：当前播报行会显示全部标记图标，已播报行会向上滚动并逐渐淡化；可配置是否显示标记文字、保留的历史行数、行间距以及图标与文字间距。
* 将官方路书 token 统一收录到内置 data.zdb，修正机械损坏提示的分类、主别名和回退关系，并新增只读自定义 ZDB 合并设置；发生冲突时始终以官方定义为准。
* 为全部官方路书 token 补齐十种界面语言的数据库翻译，并按各语言常用的拉力路书术语校对；路书编辑器和图形路书 dashboard 现在都会按当前界面语言显示 token 含义，自定义 ZDB 也可补充翻译。
* 补全核心界面的德语、西班牙语、法语、意大利语、日语、韩语、巴西葡萄牙语和俄语翻译，解决设置、回放、诊断、托盘、数据迁移、路书编辑器与弹窗意外回退为英文的问题。
* 为未来的 SteamOS 和 Steam Deck 支持建立跨平台运行基础：拆分应用数据路径和音频平台服务，新增原生 Linux 诊断宿主、便携测试与 Flatpak 开发包，并已在 Linux/Flatpak 中验证官方路书数据库、Codemasters UDP 游戏插件及配置的加载。当前仍为开发基础，尚不代表完整的 SteamOS 客户端。
* 扩展 SteamOS/Flatpak 遥测验证：新增 Codemasters UDP 数据模拟器，确认宿主发送的有效数据可穿过 Flatpak 沙箱并被完整解码为车速、档位、转速和赛段距离。
* 将 BeamNG 和 ACR 的专属 WPF 设置面板重构为通用游戏集成设置：目录、开关、状态、确认及安装/注入操作现在由平台无关模型描述并由 Base.UI 统一渲染；两个游戏插件不再依赖 Base.UI，BeamNG 核心也可构建为便携 .NET 插件。
* Linux 原生宿主新增 PortAudio 播放后端，并共享现有的语音解码、混音、顺序播放、变速、静音和诊断能力；已在 Arch Linux 虚拟机中验证音频设备枚举与播放链路。
* 统一 Windows 与 Linux 的资源、游戏插件、profile、领航员语音包和前置条件初始化流程，并让 DiRT Rally、DiRT Rally 2.0 与 EA SPORTS WRC 的配置检查能够定位 Steam Proton prefix 中的 Documents 目录。
* 网页仪表盘已从 WPF、原生悬浮窗和 SharpDX 中独立出来，并接入 Linux Runtime；SteamOS/Linux 现在能够加载全部内置仪表盘、网页客户端、字体和路书图标，并将 Codemasters UDP 遥测实时发送到浏览器仪表盘。
* 原生 Linux 宿主现在能够识别 Steam Proton 中已运行或随后启动的 DiRT Rally、DiRT Rally 2.0 与 EA SPORTS WRC，自动选择对应游戏并建立、切换和释放遥测读取器；Flatpak 沙箱内的自动发现仍需后续的宿主生命周期 relay。
* 新增面向 SteamOS 的 x86_64 AppImage 打包流程，完整携带官方路书数据库、多语言、网页仪表盘、字体、路书图标、默认 profile 和默认领航员语音包；首次启动时会将可修改的默认资源部署到用户数据目录。
* Linux 游戏检测现在会建立与 Windows 共用的完整游戏会话，统一完成 profile 与领航员选择、路书处理、PortAudio 播放和网页仪表盘状态发布，并在游戏退出或切换时可靠释放整个会话。
* 修复原生 Linux 版 DiRT Rally 使用 Feral Interactive 数据目录时被误报为“游戏未安装”的问题；现在能够识别 Steam 安装清单和原生配置路径，并准确提示尚未开启 UDP 遥测。
* 继续为 Avalonia/SteamOS 界面统一共享 Runtime：更新检查与版本配置迁移、领航员选择、静音与试听、网页仪表盘控制以及支持诊断现在均可跨平台复用；Windows 原生 HUD、更新弹窗和安装程序替换仍由 Windows Host 负责。
* 进一步统一 Windows 与 SteamOS 的回放和领航员语音包操作：回放列表、分析、锁定与导出，以及语音包导入、导出和更新安装现在均可由跨平台界面复用；应用更新安装包改为可靠的流式下载并在失败时清理临时文件，Windows 仍负责显示进度、启动安装程序和退出。
* 统一在线领航员语音包的目录检查、流式下载和安全安装流程，供 Windows 与 SteamOS 界面共用；下载或安装失败时会清理临时文件并恢复更新状态，不再让更新操作停留在进行中。
* 新增基于 Avalonia 和 FluentAvalonia 的跨平台桌面界面，并接入共享 Runtime、游戏进程监听、完整游戏会话、PortAudio 播放与网页仪表盘；Windows 与 SteamOS 使用同一套核心业务流程。
* 修正 Avalonia 界面迁移偏离现有 WPF 产品设计的问题：恢复原有主界面文案、领航员卡片与四个快捷操作、Home 页抽象仪表入口、第二导航项的通用设置、带版本号的自定义标题栏，以及疑难解答、问题反馈和赞助入口。
* Avalonia 界面现在直接复用现有十种语言的 WPF 多语言资源，并补充仪表盘语言资源加载；切换界面语言时会同步刷新领航员、仪表盘名称和相关说明。
* 完善跨平台网页仪表盘界面：主页显示可点击的真实仪表预览，仪表盘页面提供可点击访问地址、端口、刷新率和完整仪表列表，并统一各页面与主页的左右边距。
* 完善跨平台日志和音频设备生命周期：日志写入统一 Data Home 的 logs 目录并记录启动环境、初始化及未处理异常；PortAudio 会过滤不可用设备、处理运行期间的设备增删与迁移，并降低延迟、削波和爆音风险。

v2.99.99.45-3.0-rc17

* 修复 DiRT Rally 和 DiRT Rally 2.0 配置文件使用无效 XML 编码声明时被误报为“配置文件损坏”的问题；现在会回退使用 UTF-8/BOM 解析。

* 修复部分仪表盘将整数档位显示为带小数后缀（例如 1.0）的问题，包括网页仪表盘的浏览器端渲染。
* 新增供 WPF 和网页仪表盘视图共用的 128 像素图形路书图标目录，并支持将路书 token 的别名解析到标准图标。
* 路书编辑器新增图形路书预览，并为 A4 PDF 导出提供可记忆的 50%-200% 大小调节和 5-30 mm 左右/上下页边距设置。

v2.99.99.44-3.0-rc16

* 提升 ACR 实时路书 bridge 在 FMOD 资源高频调用时的可靠性：使用队列和重试来写入命名管道，并独立处理接收到的消息。
* 已注入的实验性 ACR bridge 现被识别为“已加载”，不再显示注入失败。
* 修复 ZTMZ 自动选择已运行的同一游戏时的重复初始化；此前在 ACR 已处于赛道中接入时，可能导致 ZTMZ 退出。
* 恢复回放分析图的距离轴缩放和拖动平移。
* 修复在可滚动布局中打开回放分析页时可能导致程序退出的问题。
* ACR 现在会从车辆名称的最后一个单词中识别并上报 Rally2、H3、WRC 等车辆组别。
* 修复旧 replay 数据库在每次启动时重复扫描和校验导致程序启动缓慢的问题；首次成功导入后会跳过未变化的数据库，并在日志中记录详细进度和各阶段耗时。
* 修复主页“游戏设置”“游戏悬浮仪表盘”和“领航员”标题不会随界面字体大小设置实时调整的问题；新下载的推荐字体现在无需重启即可立即应用。
* ZTMZ 在 ACR 赛段已开始后接入时，会恢复赛段状态，不会重复播报发车倒计时或 Go 语音。
* 本地化 ACR 共享内存、bridge 和前置检查状态文本。
* 提醒 ACR 与 ZTMZ 必须以相同 Windows 权限级别运行，否则实时 bridge 无法传送路书。
* 修复安装后网页仪表盘客户端文件和内置字体缺失的问题。
* 新增悬浮仪表盘使用提示，并让调试仪表盘显示可读的游戏状态名称。
