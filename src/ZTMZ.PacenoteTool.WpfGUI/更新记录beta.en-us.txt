v2.99.99.45-3.0-rc17

* Fixes DiRT Rally and DiRT Rally 2.0 configuration files with an invalid XML encoding declaration being incorrectly reported as corrupted; ZTMZ now falls back to UTF-8/BOM parsing.
* Prioritizes physical Wi-Fi and Ethernet addresses for the Web Dashboard; VPN and virtual-network addresses remain available but are listed later.

v2.99.99.44-3.0-rc16

* Fixes Home page section titles not updating with the interface font-size setting and lets newly downloaded recommended fonts apply without restarting.
* Restores ACR stage state when ZTMZ joins an already running stage, without replaying the start countdown or Go call.
* Localizes ACR shared-memory, bridge, and prerequisite status messages.
* Warns when ACR and ZTMZ run at different Windows privilege levels, which prevents the live bridge from delivering pacenotes.
* Makes the ACR live-pacenote bridge reliable during bursts of FMOD resource calls by queueing and retrying named-pipe writes, then processing received messages independently.
* Treats an experimental ACR bridge that is already injected as loaded instead of reporting an injection failure.
* Fixes automatic game selection reinitializing the same running game, which could close ZTMZ when it joined ACR while already on a stage.
* Restores replay-analysis distance-axis zooming and panning.
* Fixes a crash when opening the replay analysis tab in a scrollable layout.
* Reports ACR vehicle classes such as Rally2, H3, and WRC from the final word of the vehicle model name.
* Fixes slow startup caused by repeatedly scanning and validating unchanged legacy replay databases; they are now skipped after their first successful import, with detailed startup progress and timing diagnostics in the log.
* Fixes installation of the Web Dashboard client files and bundled fonts.
* Adds an overlay-dashboard usage hint and readable game-state names in the diagnostics dashboard.

v2.99.99.43-3.0-rc15

* Fixes an rc14 issue that could leave ACR co-driver calls silent after bridge injection on a new PC.
* Adds the ACR start procedure, with ZTMZ's 5-4-3-2-1 countdown and Go call.
* Adds normal-finish, disqualification, collision, and out-of-track handling for ACR stages.
* Expands ACR spoken pacenote coverage, including distance calls and common hazards and landmarks.
* Keeps the ACR dashboard visible while ACR has focus and shows it only when a stage begins.
* Offers bridge injection once experimental support is enabled and ACR is ready, regardless of launch order.
* Installs a missing ASP.NET Core Runtime after the .NET Desktop Runtime, with Gitee mirrors for China Standard Time.
* Adds an interface font-size setting, adjustable from 85% to 130%.
* Adds an offline pacenote script editor with validation, CrewChief JSON import, live playback highlighting, distance adjustment, and roadbook PDF export.

v2.99.99.42-3.0-rc14

* Adds experimental opt-in Assetto Corsa Rally support with live in-game pacenote forwarding.
* Adds a clear injection warning, localized bridge state, and bridge availability to home diagnostics.
* Fixes the Home page layout: game settings now scroll correctly and the diagnostics status bar remains visible.
* Adds configurable UI fonts: choose a system font or download and apply recommended open-source fonts on demand.
* Adds the online [AI] Hajimi voice package, generated with CosyVoice 3 and multiple randomly selected takes per token.

v2.99.99.41-3.0-rc13

* Adds BeamNG.drive Rally Mode support, including live co-driver calls, countdowns, stage state, telemetry, and automatic Rally Bridge setup and updates.
* Adds vehicle-damage dashboards and optional system voice alerts for BeamNG.drive and Richard Burns Rally.
* Improves game detection, stage lifecycle handling, and dashboard reliability.

v2.99.99.40-3.0-rc12

* Consolidates improvements since v2.99.99.36-rc9: the .NET 10 and WPF-UI update, safer game telemetry ports, and more reliable UDP and audio handling.
* Adds a China-friendly .NET desktop-runtime download mirror for the installer when Windows is configured for China Standard Time.
* Improves update delivery when the application starts minimized: an available update is announced through the tray icon and remains available from the tray menu.
