v2.99.99.46-3.0-rc18

* Adds an in-window roadbook print dialog with an exact live PDF preview, physical-printer and PDF destinations, paper size, orientation, margins, configurable page-number format and position, page ranges, and copies; printed backgrounds are preserved and browser file-path headers and footers are removed.
* Improves Windows application and tray icons with high-quality multi-resolution frames from 16 through 256 pixels, so taskbar, title-bar, Start menu, and high-DPI shell surfaces no longer rely on temporary scaling of one 256px icon.
* Upgrades audio playback to NAudio 3 and WASAPI shared-mode media sessions; fixes Windows treating pacenote playback as communications activity and automatically lowering or muting game and other application audio, while improving output-device identification and switching reliability.
* Fixes game-specific descriptions, setup guidance, bridge warnings, diagnostics, and settings remaining in English when the interface uses German, Spanish, French, Italian, Japanese, Korean, Brazilian Portuguese, or Russian.
* Shows every language in the language selector using its own native name instead of translating the entire list into the Windows display language.
* Adds a visual pacenote dashboard for the native overlay and Web Dashboard, showing every token in the current call as an icon while previous calls scroll upward and fade; token labels, history length, row spacing, and icon-to-label spacing are configurable.
* Makes the bundled data.zdb the authoritative catalog for official pacenote tokens, fixes the classification, primary aliases, and fallbacks of mechanical-damage calls, and adds an optional read-only custom ZDB merge with official definitions taking priority.
* Adds rally-oriented database translations for every official pacenote token in all ten interface languages; the script editor and visual dashboard now show token meanings in the current interface language, with merge support for custom ZDB translations.
* Completes German, Spanish, French, Italian, Japanese, Korean, Brazilian Portuguese, and Russian translations for the core interface, eliminating unintended English fallback across settings, replays, diagnostics, the system tray, data migration, the script editor, and dialogs.
* Establishes the cross-platform runtime foundation for future SteamOS and Steam Deck support by separating application paths and audio platform services, adding a native Linux diagnostics host, portable tests, and a Flatpak development package, and verifying the official pacenote database and Codemasters UDP providers on Linux. This is development infrastructure, not yet a complete SteamOS client.
* Extends SteamOS/Flatpak telemetry validation with a Codemasters UDP simulator, confirming that valid host-side packets cross the Flatpak sandbox boundary and decode correctly into speed, gear, RPM, and stage distance.
* Replaces the BeamNG and ACR game-specific WPF settings panes with a generic game-integration settings model: paths, toggles, status, confirmations, and install/inject actions are now described without a UI dependency and rendered centrally by Base.UI. Both game plugins no longer depend on Base.UI, and the BeamNG core can now build as a portable .NET plugin.
* Adds a PortAudio output backend to the native Linux host while sharing the existing decoding, mixing, sequential playback, speed control, mute, and diagnostics behavior; audio-device enumeration and playback have been validated on an Arch Linux VM.
* Unifies Windows and Linux initialization of resources, game plugins, profiles, co-drivers, and prerequisites, and lets the DiRT Rally, DiRT Rally 2.0, and EA SPORTS WRC checks locate their Documents directories inside Steam Proton prefixes.
* Extracts the Web Dashboard from WPF, the native overlay, and SharpDX and connects it to the Linux runtime; SteamOS/Linux can now load all bundled dashboards, the browser client, fonts, and pacenote icons and stream Codemasters UDP telemetry to browser dashboards in real time.
* Lets the native Linux host detect DiRT Rally, DiRT Rally 2.0, and EA SPORTS WRC already running or subsequently launched through Steam Proton, automatically select the matching game, and create, switch, and release its telemetry reader; automatic discovery inside the Flatpak sandbox still requires a future host lifecycle relay.
* Adds an x86_64 AppImage packaging flow for SteamOS, bundling the official pacenote database, localization, Web Dashboard, fonts, pacenote icons, default profile, and default co-driver package; mutable default resources are provisioned into the user data directory on first launch.
* Makes Linux game detection activate the same complete game session used by Windows, including profile and co-driver selection, pacenote processing, PortAudio playback, and Web Dashboard state publication, with reliable release when games exit or change.
* Fixes native Feral Interactive DiRT Rally installations being reported as not installed on Linux; ZTMZ now recognizes the Steam manifest and native configuration path and accurately reports when UDP telemetry still needs to be enabled.
* Continues the shared Runtime foundation for an Avalonia/SteamOS UI: update checks and configuration migrations, co-driver selection, mute and example playback, Web Dashboard control, and support diagnostics are now reusable across platforms, while the native HUD, update dialogs, and installer replacement remain Windows Host responsibilities.
* Further unifies replay and co-driver package operations across Windows and SteamOS: replay listing, analysis, locking, and export, plus co-driver package import, export, and update installation, are now reusable by cross-platform UIs; application installers use reliable streamed downloads with failed temporary files cleaned up, while Windows still presents progress, launches the installer, and exits.
* Unifies online co-driver package catalog checks, streamed downloads, and safe installation for Windows and SteamOS UIs; failed downloads or installations now clean up temporary files and restore update state instead of leaving an update stuck in progress.
* Adds a cross-platform desktop UI based on Avalonia and FluentAvalonia and connects it to the shared Runtime, game-process monitoring, complete game sessions, PortAudio playback, and Web Dashboard so Windows and SteamOS use the same core workflows.
* Corrects the Avalonia migration where it had diverged from the established WPF product design, restoring the original Home-page wording, co-driver card and four quick actions, abstract Dashboard entry on Home, General settings as the second navigation item, versioned custom title bar, troubleshooting, issue-reporting, and support entries.
* Makes Avalonia reuse the existing WPF localization resources for all ten interface languages and load Dashboard localization resources; changing the interface language now refreshes co-driver and Dashboard names and descriptions.
* Completes the cross-platform Web Dashboard UI with a clickable real Dashboard preview on Home, a clickable access address, port and refresh-rate controls, the full Dashboard catalog, and page margins aligned with Home.
* Completes cross-platform logging and audio-device lifecycle handling: logs use the shared Data Home logs directory and capture startup context, initialization failures, and unhandled exceptions; PortAudio filters unusable devices, follows device additions/removals and migration, and reduces latency, clipping, and crackling risks.

v2.99.99.45-3.0-rc17

* Fixes DiRT Rally and DiRT Rally 2.0 configuration files with an invalid XML encoding declaration being incorrectly reported as corrupted; ZTMZ now falls back to UTF-8/BOM parsing.
* Prioritizes physical Wi-Fi and Ethernet addresses for the Web Dashboard; VPN and virtual-network addresses remain available but are listed later.
* Fixes the installer omitting the Monaco assets required by the offline pacenote script editor; packaging now fails if those assets are missing.
* Fixes some dashboards displaying integer gear values with a decimal suffix (for example, 1.0), including Web Dashboard browser rendering.
* Adds a shared 128 px graphical pacenote icon catalog for WPF and Web Dashboard views, including canonical resolution for alternate token names.
* Adds graphical pacenote previews to the script editor, with persistent 50%-200% sizing and 5-30 mm horizontal/vertical margin controls for A4 PDF exports.

v2.99.99.44-3.0-rc16

* Fixes Home page section titles not updating with the interface font-size setting and lets newly downloaded recommended fonts apply without restarting.
* Restores ACR stage state when ZTMZ joins an already running stage, without replaying the start countdown or Go call.
* Localizes ACR shared-memory, bridge, and prerequisite status messages.
* Warns when ACR and ZTMZ run at different Windows privilege levels, which prevents the live bridge from delivering pacenotes.
* Makes the ACR live-pacenote bridge reliable during bursts of FMOD resource calls by queueing and retrying named-pipe writes, then processing received messages independently.
* Treats an experimental ACR bridge that is already injected as loaded instead of reporting an injection failure.
* Fixes automatic game selection reinitializing the same running game, which could close ZTMZ when it joined ACR while already on a stage.
* Restores replay-analysis distance-axis zooming and panning.
* Fixes a crash when opening the replay analysis tab in a scrollable layout.
* Reports ACR vehicle classes such as Rally2, H3, and WRC from the final word of the vehicle model name.
* Fixes slow startup caused by repeatedly scanning and validating unchanged legacy replay databases; they are now skipped after their first successful import, with detailed startup progress and timing diagnostics in the log.
* Fixes installation of the Web Dashboard client files and bundled fonts.
* Adds an overlay-dashboard usage hint and readable game-state names in the diagnostics dashboard.
