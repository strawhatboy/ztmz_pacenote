# 启动语音更新检查与设置搜索

2026-10-13。适用于 WPF 与 Avalonia；版本号和自动更新清单未改动。

## 语音包

- 常规设置新增 `CheckVoicePackageUpdatesOnStartup`，默认开启，使用已有用户配置持久化。启动完成后后台检查，最多等待 30 秒；不下载安装、不弹模态框、不恢复最小化窗口。无已安装语音包时不检查。关闭后仍可在领航员页面手动刷新。
- 导航“领航员”显示红色数量角标；具体可更新语音包显示红点。仅统计已安装且版本落后的包，排除尚未下载的包、相同/较新版本，并按包 ID 去重。浏览页面不会清除角标。
- 共用 `CoDriverPackageUpdateService.Notifications`；安装/导入达到线上版本后清除对应状态，失败保留。安装期间发起的旧请求不得重新恢复过期角标。网络失败保留已有列表和已知更新，Avalonia 启动先加载本地包。
- WPF 使用 WPF-UI 原生 `NavigationViewItem.InfoBadge`、数字样式及 `DotInfoBadgeStyle`，`Critical` 为红色。Avalonia 使用红色计数徽标及圆点。系统通知遵循现有通知开关，WPF 另有可关闭的页顶提示及查看按钮。

## 设置搜索

两端均在主窗口标题栏中央输入名称或说明关键词，支持当前语言与英文，多个词要求全部匹配，大小写不敏感并兼容全角英文。点击后进入页面、滚动并短暂标记设置，不修改配置值。

- WPF 使用 WPF-UI 的 `TitleBar.CenterContent`；Avalonia 使用现有 FluentAvalonia 自定义标题栏，中间搜索栏两侧等宽，输入区标记为 `User` 并排除窗口拖动。帮助/问题入口保留图标和提示，长标题省略，避免窄窗口重叠。
- 结果以下拉浮层显示，不挤压页面；空结果有提示，Enter 打开第一项，Esc 或点击外部关闭浮层，选择后清空搜索并定位设置。Linux 沿用现有 X11/XWayland 窗口装饰，搜索在应用自绘顶部栏内。
- 搜索框左侧显示搜索图标；采用最小高度 32 和紧凑内边距，不固定文字区域高度。WPF 默认内边距为上下 8/7，原固定 32 高度下 14 号中文仅有 15 像素可视高度，会裁切约 17.8 像素的文字；回归测试验证 14/16/18 号中文的完整可视高度。

- WPF 索引来自随程序集嵌入的设置 XAML 和显式 `SettingsSearch.Anchor`，涵盖常规、播放、语音、仪表、VR、回放及数据目录入口。包含标题、描述和选项的资源键；不在搜索时实例化全部页面。新设置卡片需添加 Anchor。
- Avalonia 索引来自已创建页面中的设置卡片文本和对应翻译键，涵盖常规、播放、语音、仪表、回放遥测设置；语音搜索会打开语音设置子页。新卡片使用 `setting-card` 或 `search-setting` 类。尚未索引动态游戏插件设置或 Lua 仪表设置。
- 添加了十种现有界面语言的新增文案。搜索结果不是全程序命令搜索。

## 回归验证

共享测试覆盖启动检查开关/空包列表、单次执行、离线/损坏 JSON、更新分类和去重、安装后角标清除、旧异步响应、导入较旧版本、中文/英文/全角关键词。WPF 测试验证七页嵌入索引、Anchor 唯一性、折叠内容定位及展开。Avalonia 测试覆盖提示级别、角标绑定状态、启动开关、离线本地包、搜索导航及遥测页面加载、Windows RBR 构建资源。

标题栏调整后，额外使用实际 WPF 标题栏 XAML 验证窄/宽窗口布局、浮层宽度及脱离窗口树后的结果命令绑定；Avalonia 使用完整窗口验证搜索框位于标题栏、窄/宽窗口居中且不覆盖操作按钮、排除拖动、无结果提示、Esc 关闭及选中后跳转。WPF 搜索测试 3 项和 Avalonia 测试 21 项通过。

MoTeC 格式和 RBR 判定依据/限制见 [RBRPacenoteSelectionAndMotecExport.md](RBRPacenoteSelectionAndMotecExport.md)。编译和模拟 UI 测试不代替真实游戏与 MoTeC i2 人工验收；未生成发布安装包。

本轮结果：共享服务/导出测试 17 项、WPF 搜索及 RBR 相关测试 22 项、Avalonia 测试 21 项全部通过。WPF、Avalonia Windows 和 Avalonia 的 Linux 条件编译通过。Linux 检查在 Windows 主机指定 `OS=Unix` 并提供已有 ACR 原生桥接产物，未在 Linux VM 内运行。构建跳过未改动的原生仪表盘及 Avalonia 构建遥测；原有编译警告仍存在。
