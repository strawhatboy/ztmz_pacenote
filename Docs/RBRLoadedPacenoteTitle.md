## 结论与实测

游戏画面的 `Pacenote: Zloty Las - Witoszow LuppisV3_1` 对应 **RSF 的当前加载标题字段**。PaceNote.dll 负责路书处理，但不应把它的配置定义名称当作赛道路书标题。直接读取 RSF 的当前标题和加载文件，比推断 NGPCarMenu 的选择标记更准确。

## 定位记录

复用了 `build/ida-pacenote/PaceNote_analysis.idb` / `PaceNote_ida_report.txt` 和 `tmp/rsf-results.idb`，在副本分析。RSF 的静态字符串混淆使初始字符串搜索无法直接找到 `Pacenote:`；全内存搜索仅用于定位，**不用于产品运行时**。

实际支持版本：RSF 0.60.5076.0，SHA-256 `F9B7D8AA504DF0C6D046BB94B439ED3699756364583D6559578BC3DA29865F97`。RBR 可执行文件校验沿用 native-result reader 的 `5BB1B0C8F6719FAECAD63B0AAFD7541089D1D1FF7A4C9BB68ED49BB53DC6F63B`。下列地址全部为 **RSF 模块 RVA**，不能写死本次进程的加载基址。

| RVA | 含义 |
| --- | --- |
| `0x3C20FC` | 当前 RSF 赛道编号 |
| `0x3C2554` | 当前自定义路书目录（定位证据；产品无需读取） |
| `0x3C2564` | 当前加载的完整路书文件路径对象 |
| `0x3C2574` | 当前加载的路书标题对象 |
| `0x3C261D` | 字符串编码表已初始化标志 |
| `0x3C27A0` | 92 字节循环 XOR 表；只读当前进程中的表，不硬编码内容 |
| `0x2A594C` | 上述字符串对象的虚表 |

字符串对象由虚表、32 位数据指针、容量、实际字节数构成（各 4 字节）。`sub_10004EF0` 编码，`sub_100050D0` 复制对象，`sub_1000D7B0` 解码。按字节与 92 字节表循环异或得到文本。

加载函数 `sub_10167210` 在进入新加载时把路径/标题长度清零，成功路径分别写入它们；`sub_10168F60` 也更新这些字段。`sub_101AF9B0` / `sub_101B34F0` 读取标题用于游戏显示。IDA 的首选镜像基址为 `0x10000000`。分析输出保存在忽略的 `tmp/rsf-title-lifecycle.txt`、`rsf-string.txt` 等；本文记录产品依赖的结论，不提交反编译全文或游戏二进制。

`0x3C2800` 只是最后一次格式化日志缓冲区，即使含有 `Using MyPacenotes ...` 也不能作为当前加载证据。PaceNote 的 `4094/4095` 元数据解码是另一条路径，返回定义文件标识，并不等同于这里的赛道路书名称。

## 产品行为

- 路书读取时惰性发现 RSF 模块并校验版本。仅接受已加载赛道的 Racing/Paused/Replay/RaceBegin 状态，且无原生过渡；菜单/加载/重开期间的残留标题无效。
- 原生赛道编号、RSF 编号、请求的赛道编号必须一致，且已有有效的内存路书数组。校验字符串长度、虚表、可读性、标题与完整 INI 文件名一致；读前后复核状态、根指针、数组头、字符串头/内容及编码表，拒绝可观察到的变化。这不是原子快照保证。
- 当前标题包含 `Luppis`（不区分大小写）时优先采用自定义映射，并使用实际加载的文件作为内存读取失败时的文件回退；不再因 `latest` 文件时间相同而误报。
- 成功时向现有单条游戏消息区域发布“已确认加载”的成功提示，替换上一赛道可能留下的警告。Windows WPF/Avalonia 共享此行为。
- 明确的 `_default` 标题采用默认映射；其他非 Luppis 标题仅说明实际加载名称，沿用自定义文件映射规则，**不把“不含 Luppis”等同于默认路书或未安装**。
- 未验证的 RSF/游戏版本、模块不存在、空标题、不完整或不同赛道的读取均回退至已有磁盘选择逻辑，不推测运行时标题。不会改游戏文件或用户路书。

本次相关测试共 67 项通过（包含磁盘选择与退赛检测回归）。新增测试覆盖重定位、XOR 周期边界、UTF-8 名称、缺失内存、异常长度/布局、旧赛道/菜单/重开、原地字符串变化、名称/路径不匹配、Luppis 大小写、磁盘证据优先级、默认及其他名称。当前已实测 Luppis 加载；用户暂不方便切换默认路书，这项和其他 RSF 版本的人工验收仍待进行，不能由合成测试声称已完成。
