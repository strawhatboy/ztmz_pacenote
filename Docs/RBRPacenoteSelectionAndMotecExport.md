# RBR 路书提示与 MoTeC 回放导出

2026-10-13，对应 Gitee [IKL45P](https://gitee.com/ztmz/ztmz_pacenote/issues/IKL45P) 和 [IBLDGX](https://gitee.com/ztmz/ztmz_pacenote/issues/IBLDGX)。

## RBR 路书选择

`RBRPacenoteSelectionResolver` 读取安装目录下 `Plugins/NGPCarMenu.ini` 的 `Default/MyPacenotesPath`，再读取赛道目录（包含 ` BTB` 后缀兼容）中的 `mypacenote_*.txt` 选择标记。

状态独立区分：没有路径配置、已禁用、配置目录不存在、目录存在但没有此赛道、已选默认路书、已选自定义文件、无法确定。前三种也不能证明整个路书包未安装；缺少赛道不再建议重装整个路书包。用户主动选默认路书和缺少赛道使用普通信息提示，损坏路径或不确定选择使用警告。

明确选中的文件同时用于映射数据库选择和内存不可读时的文件回退；不再无视具体选择而读取另一份较新的 INI。无关 `readme.txt` 不参与判断，标记及扩展名忽略大小写，绝对路径和相对路径均支持。每次读取重新解析，避免用户在游戏中换路书后使用缓存结果。不再依赖 `Maps/Tracks.ini` 成功读取才加载自定义路书配置。

重要边界：这是 **NGPCarMenu 磁盘配置的选择结果**，不是直接读取 PaceNote.dll 已加载路书的标题。没有使用“缺少高位自定义 ID ⇒ 默认路书”的规则。只有标准类型的自定义文件仍使用自定义映射。`latest` 的候选时间相同时无法证明加载了哪份文件：提示“不确定”，保留原有枚举顺序和映射选择，不在此次提示修复中擅自换映射。未来若取得已验证的插件运行时标题/文件名来源，可提高这一处准确性。

## MoTeC 导出

WPF 回放列表增加“导出 MoTeC 遥测（实验性）”，选择输出目录后生成独立的 `MoTeC-<回放ID>-<唯一标识>/telemetry.ld` 和 `telemetry.ldx`。不会覆盖现有导出和 i2 用户批注，不依赖视频或 FFmpeg。数据库读取、重采样和写文件全部在后台执行，界面显示忙碌条。

Avalonia 的“回放”页面使用相同 Core 导出器：可选择游戏、刷新已保存比赛、选择记录及输出目录，并显示导出路径与错误。运行时启用共享回放记录，遵循 `ReplaySave`，页面提供保存遥测开关；OBS 视频录制仍关闭。两端导出格式、校验与限制相同。比赛完成后保存，未完成的当前比赛不会出现在列表中。

Avalonia Windows 构建/发布现包含 RBR DLL、插件语言及 `default.zdb` / `jannemod_v3.zdb`，启动时使用已有 PackagedFileProvisioner 更新内置映射。运行时订阅游戏 `onCustomMessage`，主页保留普通信息/警告/错误的级别。RBR 提示逻辑共享同一 DLL；Linux 的 RBR 进程读取尚未移植，因此不打包 Windows RBR DLL，也不声称支持 Linux RBR。MoTeC 与搜索/语音更新不受此限制。

初版通道：赛段时间（秒）、距离（米）、速度（km/h）、RPM、档位、油门/刹车/离合/手刹/转向（归一化值转百分比）、位置 XYZ（米）。保持原有转向符号，不把它假装成方向盘角度。暂不导出单位尚未统一核实的 G 值、悬架及温度字段。

旧数据库没有“此通道有效”的标志，因此可选通道全程为零时不输出；这也意味着真正全程为零的可选通道会被省略。只有时间/距离的旧回放仍可导出这两个通道，不虚构车辆遥测。建议在回放设置中启用遥测保存后再录制。

按原始正时间间隔的中位数选择最接近的整数采样率（格式范围限制在 1–1000 Hz），默认约 200 ms 的记录导出为 5 Hz。使用赛段时间，不使用电脑墙钟；输出从首个真实样本开始，`Stage Time` 保留原赛段时间偏移。连续量线性插值，档位保持到实际切换采样点。删除录制器插入的空起点，同时间重复样本取最后一条。不会把普通 5 Hz 回放伪装成高精度遥测。

少于两点、时间倒退、非有限值、过大的时间跳变或样本数拒绝导出，不插值填满长空洞。这包含部分 RBR 救援/罚时造成的赛段时钟跳变：后续可做分段导出，当前明确失败。仅在完整起终点都有记录且未退赛时写入圈界；部分记录不伪造完整圈或最快圈。

格式参考 [Aim_2_MoTeC](https://github.com/ludovicb1239/Aim_2_MoTeC) 的 MIT 实现，许可随 Core 输出到 `ThirdPartyNotices/Aim_2_MoTeC.txt`。使用明确的字段布局，不复制原作者样本日志中的不透明头部。固定宽度元数据采用参考实现的 UTF-8；非 ASCII 名称在不同 i2 版本中的展示还需要人工验证。

## 验证和剩余验收

- RBR 测试覆盖缺少配置/节/键、禁用、目录缺失、缺少赛道、具体选择、显式默认文件、README 干扰、大小写、`latest`、相同时间戳、冲突标记、缺失文件、绝对路径、BTB、配置变更，以及无 Tracks.ini/无高位 ID 时的公开 reader 路径；另跑已有安装路径和映射测试。
- MoTeC 测试独立读取二进制头、通道链、数据指针、单位、采样率及样本值；覆盖不规则时间、档位阶跃、重复时间、纯计时回放、非法值、时间跳变、取消、地区格式、退赛及重复导出保护。
- 独立 `gotzl/ldparser` 读取器验证了导出通道，不使用生产 writer 回读自己的格式。它的元数据解码仅支持 ASCII，中文标题会被它忽略；通道数值读取正常。
- 本机 `replays.zdb` 以只读连接验证：回放 2（Jodlownik - Woliborz）和 3（Vinec-Skalsko NIGHT）可导出为 5 Hz；回放 1 的赛段时间从 453.408 秒跳到 473.441 秒（墙钟只过约 35 ms），按时间跳变规则拒绝，不虚构这 20 秒的数据。
- 尚未在真正 MoTeC i2 中打开验收，故入口保留“实验性”。人工验收应检查时间轴、速度/RPM/档位/踏板、部分记录、长赛段以及非英文赛道名，再考虑结束实验状态。
- Windows 托管编译/测试使用 `-p:_NativeDashboardEnabled=false` 跳过本次无改动的原生仪表盘构建；这不构成安装包或原生 DLL 的发布验证。

语音包启动更新检查、导航角标及设置搜索已在后续改动实现，见 [StartupVoiceUpdatesAndSettingsSearch.md](StartupVoiceUpdatesAndSettingsSearch.md)。
